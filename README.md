# 🧮 CalculaFácil

Um projeto acadêmico desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de aplicar conceitos de desenvolvimento Front-end na criação de três calculadoras.

## Sobre o projeto

O CalculaFácil é um site que reúne ferramentas simples para realizar cálculos relacionados à saúde e à vida financeira.

O projeto foi desenvolvido como atividade da disciplina de **Desenvolvimento Front-end**, do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS).

## Funcionalidades

O site possui três calculadoras:

- **Calculadora de IMC:** calcula o Índice de Massa Corporal com base no peso e na altura.
- **Calculadora de TMB:** estima a Taxa Metabólica Basal considerando sexo, idade, peso e altura.
- **Calculadora de Salário Líquido:** calcula o salário após a aplicação dos descontos informados.


## Tecnologias utilizadas

- HTML5 – Estruturação do conteúdo.
- CSS3 – Estilização e organização visual.
- JavaScript – Implementação dos cálculos e funcionalidades.
